# Student-Linked-List
Robert Vazquez
Software Development 1 
CRN 31032

A Program using dynamic memory to make a stack of student objects and save and retrieve their IDs and names.

When prompted, type anything other than -1 to add new student to list.
Input ID # then name(Program will detect when # is not an integer).
When -1 is typed, all student information will be printed.
